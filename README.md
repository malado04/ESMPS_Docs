# ESMPS — Documentation officielle

**ESMPS — École Sœur Marie Paul SAGNA**

Documentation technique et fonctionnelle de l'application de gestion scolaire ESMPS.

## Présentation du projet

ESMPS est une application web de gestion scolaire développée pour accompagner les activités administratives et pédagogiques d'un établissement scolaire.

Elle vise à centraliser les informations, faciliter le suivi des élèves et des inscriptions, organiser les opérations scolaires et permettre aux utilisateurs d'accéder aux fonctionnalités correspondant à leurs responsabilités.

L'application de référence est accessible à l'adresse suivante :

**https://ecolesmps.com**

## Objectifs

* Simplifier la gestion quotidienne de l'établissement.
* Centraliser les informations scolaires.
* Faciliter le suivi des élèves et des inscriptions.
* Organiser les années scolaires.
* Faciliter la consultation et l'impression des bulletins.
* Encadrer les accès selon les profils utilisateurs.
* Améliorer la traçabilité et la disponibilité des informations.

## Technologies

L'application repose sur les technologies suivantes, sous réserve de vérification des versions exactes dans le code source :

* **Backend :** PHP et Laravel.
* **Interface :** Blade et AdminLTE.
* **Base de données :** moteur relationnel à confirmer.
* **Gestion du code source :** Git et GitHub.
* **Hébergement :** environnement web configuré pour Laravel.

## Déploiement et isolation des établissements

ESMPS suit un modèle de déploiement sur mesure : chaque établissement client dispose de sa propre instance de l'application et de sa propre base de données.

Cette architecture permet de séparer les données des établissements. La sécurité dépend également de la configuration de l'hébergement, de la gestion des comptes, des mises à jour et des sauvegardes.
